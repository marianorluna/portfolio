A shareable web panel for Revit models: model changes arrive in real time, KPIs and the table link to the 3D viewer, and you can ask questions in natural language with geometry highlighting.

## Features

<FeatureGrid>
  <Feature icon="radio" title="Real time">
    Revit changes → WebSocket (pyRevit spool + relay).
  </Feature>
  <Feature icon="eye" title="3D viewer">
    Speckle Viewer linked to the table and chat.
  </Feature>
  <Feature icon="gauge" title="KPIs">
    Cards, charts (Recharts), and a filterable table.
  </Feature>
  <Feature icon="shield" title="QC">
    Data-quality findings.
  </Feature>
  <Feature icon="sparkles" title="AI">
    Natural-language questions (DeepSeek via OpenRouter) with viewer highlighting.
  </Feature>
  <Feature icon="users" title="Roles">
    `admin` (write / ingest) and `guest` (demo with chat quota).
  </Feature>
</FeatureGrid>

## Roles

<RoleCard role="admin" title="Admin">
  Write and ingest: sync the model, manage data, and use chat without the guest quota.
</RoleCard>

<RoleCard role="guest" title="Guest">
  Public demo with a chat quota: explore KPIs, viewer, and queries up to the configured limit.
</RoleCard>
