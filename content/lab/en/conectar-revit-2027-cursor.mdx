<IntroCard icon="book" title="Introduction">

Many posts frame linking AI to Revit as a long, expensive process—or as something “only Claude can do.” **That isn’t true.** This lab shows that with **free** tools—Python, pyRevit, Cursor (Hobby or trial), and free or local AI models—and Revit on a **trial** if you don’t have a license yet, you can **talk to your model in a few minutes**.

Using the **MCP** (Model Context Protocol), **pyRevit**, and **Cursor**, you combine those pieces to chat with the model, audit parameters, automate modeling, and write scripts on the fly without leaving the chat. You don’t need to be an expert: basic knowledge plus this step-by-step guide is enough.

If you already have the prerequisites installed (Python, Revit 2027, and Cursor), the step-by-step guide usually takes **about 20 minutes** to your first prompt. If tools are still missing, budget extra time for downloads and installs.

This guide takes you from install to your first AI prompt interacting with Revit in real time. Every step explains what to do and why.

</IntroCard>

<CardGrid variant="req">

<ReqCard icon="python" title="Python installed">

You need **Python 3.12** installed globally on Windows: MCP uses it as an intermediary server. This tutorial was developed with version **3.12.7**.

1. Download the installer from [python.org/downloads](https://www.python.org/downloads/) (choose the 3.12 series).
2. In the setup wizard, check **Add python.exe to PATH** before installing.
3. Close and reopen the terminal (CMD or PowerShell) and verify:

```bash
python --version
```

You should see something like `Python 3.12.x`. If the command is not recognized, try `py --version`.

4. Install the base libraries:

```bash
pip install mcp httpx
```

</ReqCard>

<ReqCard icon="cuboid" title="Revit 2027 installed">

Works only with **Revit 2027** on **Windows**. Revit has no native Mac version (you would need a Windows virtual machine, which is out of scope for this guide). If you don’t have a paid license, Autodesk’s **trial period** is enough to follow the whole tutorial.

1. Confirm you have **Revit 2027** installed (not 2025 or 2026).
2. Work on a **Windows** PC with a valid license or **trial**.
3. Open a **project or family** — do not leave Revit on the Home screen.
4. Keep that document open while you follow the guide: the MCP server needs it active.

</ReqCard>

<ReqCard icon="sparkles" title="Cursor installed">

You need the [Cursor](https://cursor.com/download) editor. Cursor is no longer “free with no limits” like in the early days, but **you can follow this tutorial without paying**.

1. Download it from [cursor.com/download](https://cursor.com/download) and install it on Windows.
2. Create an account (**Hobby** does not require a card).
3. In step 5 you will connect it to Revit via MCP.

**Plans and cost**

- **Hobby (free):** low monthly Agent and Tab quotas. Enough to try things and finish this guide with light use; it runs out quickly with all-day use.
- **Pro trial:** new accounts often get **7–14 days** of Pro features.
- **Pro ($20/mo):** a strong option for daily use — unlimited Tab, generous Auto Mode (Cursor picks the model), and ~$20/mo in credits for frontier models (Claude, GPT, etc.).
- **Without Pro:** your own API key (BYOK) from OpenAI, Anthropic, DeepSeek, or OpenRouter — pay only API usage — or a local model with **Ollama / LM Studio** (free and unlimited; performance depends on your PC/GPU).

On Pro, **Auto Mode** does not burn your credit pool at frontier-model rates when you pick models by hand: those credits are used when you select a specific model or turn on Max Mode. Official details: [cursor.com/pricing](https://cursor.com/pricing).

<Callout variant="tip">
Hobby or the Pro trial is enough for this guide. If you hit the quota mid-month, switch to Auto Mode, wait for the cycle reset, or use BYOK / Ollama.
</Callout>

</ReqCard>

<Step number={1} title="Install pyRevit">

Download the pyRevit installer from its official GitHub repository: [github.com/pyrevitlabs/pyRevit](https://github.com/pyrevitlabs/pyRevit). Go to the **Releases** section, open the latest version, and download the **Admin / All Users** installer.

<Figure
  src="/lab/screenshots/conectar-revit-2027-cursor/01-pyrevit-github-releases.webp"
  alt="pyRevit GitHub Releases page with the Admin / All Users installer highlighted"
  caption="In Releases, download the Admin / All Users / %PROGRAMDATA% installer."
/>

The first time you open Revit after installing it, make sure to tell it to **always load** this add-in.

<Callout variant="tip">
Use the "Admin / All Users" installer to avoid permission issues.
</Callout>

</Step>

<Step number={2} title="Configure Routes in pyRevit">

Go to the **pyRevit** tab → **Settings**.

<Figure
  src="/lab/screenshots/conectar-revit-2027-cursor/02-pyrevit-settings.webp"
  alt="pyRevit ribbon in Revit with the pyRevit tab and Settings button highlighted"
  caption="pyRevit tab → Settings (gear icon)."
/>

- In the left panel, look for **Routes**.
- Turn on the **Routes Server (Beta)** switch.
- Check the **pyrevit-core/** box.
- Click **Save Settings and Reload** to apply the changes.

Your panel should look similar to this:

<Figure
  src="/lab/screenshots/conectar-revit-2027-cursor/03-pyrevit-routes.webp"
  alt="pyRevit Settings with Routes Server enabled and pyrevit-core checked"
  caption="Routes Server (Beta) on and pyrevit-core/ checked."
/>

</Step>

<Step number={3} title="Install the MCP extension">

Go to the **pyRevit** tab → **Extensions**.

<Figure
  src="/lab/screenshots/conectar-revit-2027-cursor/04-pyrevit-extensions.webp"
  alt="pyRevit ribbon in Revit with the pyRevit tab and Extensions button highlighted"
  caption="pyRevit tab → Extensions (gear icon)."
/>

Find and install the extension named `mcp-server-for-revit-python`. After installing, check that its status is **Enabled**, then reload Revit or pyRevit again.

<Figure
  src="/lab/screenshots/conectar-revit-2027-cursor/05-pyrevit-extensions-mcp.webp"
  alt="pyRevit Extensions manager showing mcp-server-for-revit-python installed and Enabled"
  caption="mcp-server-for-revit-python extension installed and Enabled."
/>

</Step>

<Step number={4} title="Verify the Revit connection">

<Callout variant="critical">
**Critical!** Open a project or family in Revit. The server will not work if you are on the Home screen.
</Callout>

Open your browser and visit:

```text
http://localhost:48884/revit_mcp/status/
```

If everything is correct you should see a JSON response like this:

```json
{
  "revit_available": true,
  "health": "healthy",
  "api_name": "revit_mcp",
  "status": "active"
}
```

<Figure
  src="/lab/screenshots/conectar-revit-2027-cursor/06-localhost-status-healthy.webp"
  alt="Browser showing healthy JSON at localhost:48884/revit_mcp/status"
  caption="healthy response: Revit is available to the MCP server."
/>

</Step>

<Step number={5} title="Configure Cursor">

If you do not have Cursor yet, download it from [cursor.com/download](https://cursor.com/download). In Cursor, open **Settings → Tools & MCPs** and click **+ New MCP Server**.

<Figure
  src="/lab/screenshots/conectar-revit-2027-cursor/07-cursor-mcp-settings.webp"
  alt="Cursor Settings Tools & MCPs with mcp-server-for-revit-python and New MCP Server"
  caption="Add a new MCP server from Settings → Tools & MCPs."
/>

Configure it as "command" with the following JSON (replace `your_user` with your real Windows username):

```json
{
  "mcp-server-for-revit-python": {
    "command": "python",
    "args": [
      "C:\\Users\\your_user\\AppData\\Roaming\\pyRevit\\Extensions\\mcp-server-for-revit-python.extension\\main.py"
    ]
  }
}
```

The path in `args` is the default extension install location. If you installed the plugin somewhere else, point `args` to that `main.py`. On Windows, use **double backslashes** (`\\`) in the JSON path; otherwise Cursor will not find the file.

Check that a **green dot** appears next to the server name: that means Cursor completed the handshake with pyRevit.

</Step>

<Step number={6} title="First test!">

Open the Cursor chat in **Agent** mode with the **Auto** model and send this prompt to verify the connection:

<PromptExample label="Example prompt">
"Check the status of Revit 2027 and tell me the name of the active document and the name of the active view."
</PromptExample>

You will see Cursor automatically invoke the `get_revit_status` tool, pull information from your model, and write it back in natural language. **Auto** is enough for this test; you can also pick stronger paid models or free local models with **Ollama / LM Studio**, as noted under [Prerequisites](#requisitos).

<Figure
  src="/lab/screenshots/conectar-revit-2027-cursor/09-cursor-chat-get-status.webp"
  alt="Cursor query in Agent mode with Auto model: prompt about active document and view, Revit MCP, and agent reply"
  caption="Example in Cursor with Agent + Auto: the agent queries Revit and replies with the active document and view."
/>

</Step>

<Section id="casos-uso">

<IntroCard icon="boxes" title="Use cases and tools">

The MCP server exposes around 20 tools that Cursor's AI can use on its own based on what you ask.

The prompts in this section are **illustrative**: they are examples and starting points. Results depend on the AI model you use and on what is in the Revit model (`.rvt` / `.rfa`) you are working in; adapt them, explore variations, and try what works in your own setup.

</IntroCard>

<CardGrid variant="tool">

<ToolCard icon="search" title="Audit and data extraction" tools={["get_current_view_elements", "list_category_parameters", "get_revit_model_info"]}>

Pull valuable information without creating temporary schedule tables.

<PromptExample label="Example prompt">
"List all walls visible in the current view, group them by family type, and tell me the total 'Volume' parameter value for each group."
</PromptExample>

</ToolCard>

<ToolCard icon="boxes" title="Modeling automation" tools={["place_family", "list_levels", "list_families"]}>

Delegate repetitive element placement or project structuring.

<PromptExample label="Example prompt">
"Find the 'Conference Table' family in the model and place one on Level 1 at exactly X:10, Y:5, Z:0."
</PromptExample>

</ToolCard>

<ToolCard icon="palette" title="Graphics and quality control" tools={["color_splash", "clear_colors", "list_revit_views"]}>

Apply color overrides instantly to highlight errors or classify elements.

<PromptExample label="Example prompt">
"Paint all 'Doors' category elements bright red in this view so I can spot them quickly. When I am done reviewing, clear the colors."
</PromptExample>

</ToolCard>

<ToolCard icon="code" title="The wildcard: direct code" tools={["execute_revit_code"]}>

If no predefined tool exists, Cursor can write and run a Revit API script on the fly.

<PromptExample label="Example prompt">
"Write and run a Python script in Revit that selects all walls in the project and copies the 'Type Mark' parameter text into the 'Comments' parameter."
</PromptExample>

</ToolCard>

</CardGrid>
